# 🎀 Breast Cancer Detection Using Deep Learning

An AI-powered Breast Cancer Detection system that classifies histopathological breast tissue images into benign and malignant categories using deep learning models and provides real-time prediction through a Flask web application.

---

## 🚀 Features

- Histopathological image classification
- Benign and malignant tumor detection
- Transfer learning-based prediction
- Explainable AI using Grad-CAM
- Real-time Flask web application
- Performance evaluation and model comparison

---

## 🛠️ Technology Stack

- Python
- TensorFlow / Keras
- VGG16
- ResNet50
- EfficientNetB7
- OpenCV
- Flask
- NumPy
- Pandas
- Matplotlib
